## D. Operator mindset (Lauren + Galaxy → drills)

From Lauren Tan (@poteto): critique cards as grounded judgment; poteto-mode + verify before swarm; you author/merge the PR, bots propose. From Lauren Kwok: recurring work on a fresh bot; don’t hammer 15-min routines. From Galaxy days: colleagues not tools; scope like a JD then trust; governed agency; SsOT outside chat; connector honesty.

**Drill A — One-job stamp.** One sentence, one duty verb. If you need “and,” split or cut.

**Drill B — Four questions before CreateAgent.** (1) What single job fails today without it? (2) Who owns Lock vs Hold on side effects? (3) Where is SsOT and what does blocked look like? (4) What proof will I check? (5) Does a living bot already own this verb?

**Drill C — Costume before Reset.** Name the kill (DNS/cert, secrets, Update 43%, empty transcripts, per-bot runner) before wipe.

**Drill D — Gate inventory.** Every irreversible action has human approve / fail-closed / quiet-when-empty / draft-only. No gate → remove the action from that bot.

**Drill E — Spec → one Cloud Agent → PR with proof → you merge.** Never YOLO infra (leave WAF). Never invent past 404/403.

**Drill F — This-week change test.** Would I change a file/setting/routine this week? If no, bank it. If yes, one action + date.

**Drill G — Quiet is success.** Green morning with no ping is rent paid, not a dead bot.
