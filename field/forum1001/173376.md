## @Colin STAFF · 2026-09-30T16:40:40
Hey @moonj_asmr , thanks for the report! On the second issue: those runs weren’t actually stuck. On our side each one was working through the Figma MCP the whole time, but some model responses took 2 to 4 minutes to start, and --output-format text only prints once the final answer is ready, so it looks frozen until then. The browser-use process is just the plugin’s MCP server starting up with the CLI, and it wasn’t being called. To see progress while it runs, try: cursor-agent ... -p --output-format stream-json --stream-partial-output "<prompt>" If you’d rather not start the browser-use server at all for these runs, cursor-agent mcp disable <name> (the name from cursor-agent mcp list ) turns it off. On the login issue: it looks like you’re running the CLI on your Grok Bot’s computer. Could you run these two commands, once in the terminal where you run cursor-agent login and once in the shell that runs the headless command? id -un; echo "HOME=$HOME XDG_CONFIG_HOME=$XDG_CONFIG_HOME" ls -la "${XDG_CONFIG_HOME:-$HOME/.config}/cursor/auth.json" If the two outputs point at different files, that explains why the next command doesn’t see the fresh login. Either way, please paste both outputs and we’ll take it from there.
