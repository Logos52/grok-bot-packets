Hey guys, while i was on a personal plan, whenever grokbot started a cloud agent to work (on a pr), it would use my personal usage, but ever since moving to our team organisation, they now use the team cloud credits, how can i make it go back to using my personal cursor usage? we use our grokbots a lot with cloud agents to review prs, or other misc stuff where we tag them

## @Colin STAFF · 2026-09-30T16:26:36
Hey @Danick , thanks for the question! Once you’re on a team, everything you run, including the cloud agents your Grok Bot starts, is billed through your team seat instead of a personal plan. There isn’t a setting that sends a team member’s usage to a separate personal subscription. The “team cloud credits” you’re seeing are a one-time promotional credit your team got for setting up a cloud agent environment. They only apply to cloud agents, and they’re used before your seat’s own included usage, so right now they’re saving your included usage rather than replacing it. Once those credits run out or expire, cloud agents will draw from your seat’s included usage automatically, the same as your other usage. As an admin you can see the credit balance and each member’s usage on the team dashboard under Usage and Billing. If you really want cloud agents billed to a separate personal plan, the only way is to run Grok Bot from a different Cursor account that isn’t a member of the team.
