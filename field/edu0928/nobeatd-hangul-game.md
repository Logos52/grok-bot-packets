# 한글 자음 모음 학습하기

자음 19개와 단모음 10개를 카드 게임으로 익히는 국어 음운 학습 프로그램입니다.

- 1~5단계 연습과 시험 스테이지로 이루어져 있습니다.
- 자음: 소리 나는 위치 · 발음하는 방식 · 소리의 세기
- 모음: 혀의 앞뒤 위치 · 입술 모양 · 혀의 높낮이

## 사용 방법

`index.html` 파일 하나로 동작합니다. 설치나 로그인이 필요 없습니다.

- 온라인: GitHub Pages 주소로 접속합니다.
- 오프라인: `index.html`을 내려받아 브라우저로 엽니다.

학습 기록은 사용하는 기기의 브라우저에만 저장됩니다. 서버로 전송되지 않습니다.
