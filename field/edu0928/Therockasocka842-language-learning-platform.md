# LinguaArc

A teaching-first language-learning platform with five independent tracks:

- Mandarin Chinese
- Japanese
- Puerto Rican Spanish
- French
- Italian

## Features

- Dedicated language dashboard for each track
- Lesson progression with explanations before quizzes
- Informational lesson sections and guided practice
- Adaptive review and mastery checkpoints
- Character and word anatomy panels
- Responsive modern UI for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

The app runs on http://localhost:3000.
