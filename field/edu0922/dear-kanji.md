# 🍻 dear幹事

〈ディア幹〉幹事のあなたへ、ギルドを。

飲み会の幹事を手助けするWebアプリです。はじめての幹事さんにも、もう数えていない玄人幹事さんにも。

**▶ 使ってみる:** https://aurorapolis.github.io/dear-kanji/

## できること

- **会のこと** … 会の名前・日にち・駅・お店、今日の終電メモ
- **お店をさがす** … 条件から「探す言葉」を作って、ホットペッパー・食べログ・地図を開く。気になったお店はメモ保存
- **参加する人** … 名簿、お店に伝える人数、乾杯・締め・プレゼント担当とお願い文
- **会費を決める** … ひとりいくら / 総額から割る、端数のゆくえ、カンパ
- **集金する** … 「済」ハンコの集金帳面、そっと一声、お誘い文、A4チラシ
- **さくっと二次会** … 九次会まで割り勘できます（九次会は、もう帰りましょう）
- **任務完了** … 全員の会費が集まったら押せる、幹事をねぎらう大きなボタン

## 大事にしていること

- このアプリは**お金を預かりません**。参加者は幹事さんに直接送ります。
- 入力した内容は、**開いた端末のブラウザ内だけ**に保存されます。サーバーには送りません。
- 人間関係を壊さないこと。お金まわりは特に慎重に。

## つくり

HTML1枚（`index.html`）で動きます。インストールも登録も不要です。
