# 🎯 刻意练习教练（Deliberate Practice Mentor）

把任何技能型学习变成**可追踪的刻意练习**——计划、拆解、练习、反馈、复盘，五步闭环。

## 市场描述（提交审核用，直接复制）

> 刻意练习教练（Deliberate Practice Mentor）：把你的技能型学习变成可追踪的刻意练习。设计长期学习计划 → i+1 目标拆解（刚好超出当前能力）→ 12 种练习方法（复现驱动/找茬验证/费曼教学/抽认卡/结构化演练等）→ 即时诊断反馈 → 掌握热力图与错误账本复盘。内置基线评估、平台期检测、间隔复习、每日打卡，让进步可量化、不迷路。适用于编程、数据工程、语言、写作等任何技能型学习。说"开始练习""拆解目标""找茬""复盘"即可触发。

## 功能一览

- **四大能力**：长期计划设计 / i+1 目标拆解 / 练习方法设计+错误指正 / 反馈与学习集合调整
- **12 种练习方法**：复现驱动、契约先行、找茬验证、费曼教学、问题驱动、架构默写、故障演练、变式场景、间隔回顾、抽认卡制造、结构化演练、苏格拉底引导
- **追踪体系**：掌握热力图（🟢🟡🔴）+ 基线评估（1-10 分）+ 错误账本（E-ENV/E-CON/E-CODE/E-DESIGN/E-COACH）+ 每日任务清单打卡
- **科学机制**：Ebbinghaus 间隔复习、平台期检测、周/月双轨回顾、练习节奏建议
- **游戏化设计**（v1.4.0）：步骤微结算（练中即时小胜利）+ 错误=情报（陷阱预告）+ 难度即时旋钮（挑战度 1-5 当场调）+ 教程关 / Boss 综合关 + 知识地图待解锁区——全程无积分/徽章/排行榜，保住「掌握感」内在动机
- **质量门禁**：DoD 必须基于学习者独立产出证据（换场景题/独立复述/独立演示），杜绝「讲解≠掌握」（E-COACH-003/004）
- **粒度校准**：每周回顾 / 每 3-4 个 goal 后校准目标粒度（偏大拆细 / 偏小合并），防长期硬撑（E-PLAN-001）

## 快速上手

1. 安装后说 **「新主题」**——教练会帮你初始化练习工作区（知识地图 + 长期计划 + 第一个目标）
2. 日常触发词：

| 你说 | 教练做 |
|------|--------|
| 「开始练习」「练习 第X单元」 | 完整练习循环（准备→练习→反馈→蒸馏→汇报） |
| 「拆解目标」 | i+1 目标拆解（含前置知识链 + 障碍预判） |
| 「找茬」「考我」 | 找茬验证 / 问题驱动 |
| 「抽卡」 | 抽认卡制造 |
| 「演练」 | 结构化演练（面试/答辩/汇报） |
| 「复盘」「反馈」 | 评估 + 学习集合调整 |
| 「回顾」 | 间隔复习 |
| 「打卡」 | 每日任务清单 |

3. 练习工作区自动生成在 `<项目>-刻意练习/` 目录，所有记录（计划/热力图/错误/反馈）都是普通 Markdown 文件，随时可见可改。

## 使用示例

- **编程学习**：「新主题，Python 数据工程，3 个月」→ 教练画知识地图、拆阶段、定里程碑
- **语言学习**：「练习 第2单元」→ 完整练习循环，DoD 全满足才闭环
- **面试准备**：「演练，模拟产品经理面试」→ 限时作答 + 维度评分 + 示范答案对比
- **复习巩固**：「回顾」→ 按热力图 next_review 做 2-3 分钟快速问答

## 方法学来源

基于 K. Anders Ericsson 的刻意练习研究、Ebbinghaus 遗忘曲线、最近发展区理论（i+1），并融合认知心理学与学习科学实践。
