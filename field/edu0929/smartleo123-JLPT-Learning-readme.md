## 資料範圍

- 來源資料夾共 23 份 PDF，沒有 2020 年 7 月試卷。
- 主要辨識每份掃描卷前 3 頁；2010.07、2011.07、2013.12 辨識前 5 頁；2019.07 前 3 頁使用可擷取文字。
- 「檢出卷次」只表示字詞或句型出現在題面或選項，不代表正確答案、全卷出現次數或官方出題率。掃描辨識可能漏算或錯讀；請依頁面中的原卷連結核對。
- 中文解說和例句為重新編寫。網站不含原始 PDF 檔。
