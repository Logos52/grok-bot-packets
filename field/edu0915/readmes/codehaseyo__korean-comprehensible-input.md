## Contributing

Found a useful Korean comprehensible-input resource?

Open a PR and include:

* Resource name
* Link
* Approximate level
* Format
* A short description of why it is useful

Resources should ideally help learners understand Korean through **Korean + context**, rather than relying primarily on English explanations.
