# Language Tutor

用中文教英语与日语的 Agent Skill。英语包含讲题、讲课和作文辅导；日语强调汉字注音、句子结构与每一步变形的理由。

## 教什么，怎样教

| 模块 | 教学方式 |
|---|---|
| 英语讲课 | 接受 CEFR、年级、考试经历、教材或实际能力描述；讲清新知识的名称、构成、含义、用法和对照。 |
| 英语讲题 | 阅读与选词填空回原文找证据，解释正确选项、诱导项和诱导句；遇到知识缺口，自动补课后返回原题。 |
| 英语作文 | 从学习者草稿开始，先看是否回应题目，再教删改、重组、论证和表达；允许删除无效句段，默认不直接代写范文。 |
| 日语听读 | 先确认教材与知识边界；日语汉字每次出现都注平假名，解释助词、修饰关系、活用和表达选择。 |

两种语言分别维护知识状态。用户要求的讲解范围、节奏和翻译边界优先；不会把通过小测设为继续学习的条件。

## 使用

本仓库根目录就是技能目录，入口为 [SKILL.md](SKILL.md)。将其安装到支持 `SKILL.md` 的客户端；安装后的目录名和调用标识保留为 `japanese-reading-tutor`，兼容原有调用，同时支持英语。

可向支持技能安装的助手发送：

> 请从 https://github.com/anberw612-stack/language-tutor 安装技能。

安装后可这样开始：

- “使用 $japanese-reading-tutor，用中文讲这篇英语阅读。我高二，先讲第 3 题。”
- “我自评 C1，但关系代词一直没学明白，先教清楚，再回到这道题。”
- “这是作文题和我的草稿，先检查是否切题，再教我修改，不要直接给整篇范文。”
- “用中文讲这段日语。我用的教材是……，目前学到……，请解释每步变形为什么需要。”

问题卡片等交互功能依客户端工具而定；技能中包含工具不可用时的文字提问方式。
