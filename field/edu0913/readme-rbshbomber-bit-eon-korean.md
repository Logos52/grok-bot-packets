# EON (언)

Learn Korean in the language you already speak.

A multilingual Korean studio: Hangul composition, contrastive grammar, daily conversation, TOPIK drills, and first-language methods for English, French, and eleven other languages.

The interface and explanations start in **English**. Switch both at the top.

## Tracks

- **Hangul** — assemble onset + vowel + batchim, hear it, then dictation
- **Grammar** — 20 lessons (particles, tense, honorifics, negation…)
- **Talk** — 18 scenes (café, clinic, restaurant, phone, market…)
- **TOPIK** — 10 item-type drills and writing frames
- **Practice** — particle gym, SRS review, phrasebook, writing
- **Methods** — 13 L1 guides (transfer, traps, three-week sequence)

Progress, review cards, and saved lines stay in the browser.

## Run

```bash
npm install
npm run dev
```

Then open the printed local URL. Typecheck: `npm run typecheck`. Production build: `npm run build`.

## Stack

React 19, TanStack Start, Tailwind v4, Zustand.
