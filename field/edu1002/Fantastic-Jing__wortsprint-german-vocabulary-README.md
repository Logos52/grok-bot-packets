# WortSprint · German B1 Vocabulary

WortSprint is a browser-based German B1.1 vocabulary learning tool for sentence-based practice. It includes staged exercises, progress tracking, flash quizzes, custom vocabulary groups, archived words, and local JSON backup.

## Run locally

Open [`WortSprint/index.html`](WortSprint/index.html) in a browser. No server or build step is required.

## Features

- German example sentences with Chinese translations and concise explanations
- Five-stage practice with local progress persistence
- Flash mode with group and progress filters
- Keyboard controls: arrow keys/WASD, number keys, Space and Enter
- Custom groups with rename, merge, delete, and word reassignment
- Import/export of learning data as JSON

The course notes, vocabulary sources, and study materials are included in this repository for personal learning and reference.
