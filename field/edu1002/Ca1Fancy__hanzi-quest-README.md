# Hanzi Quest — iPad PWA v4

Персональная PWA-игра для китайского: словарь, уроки, Quest, Pinyin, Listening, Writing и Boss.

## Что нового

- Уроки: можно выбрать все уроки, один урок или несколько (например, Урок 1 + Урок 3).
- Все режимы используют выбранный набор слов.
- Boss — общая проверка по выбранным урокам.
- Boss рекомендует слабые зоны по ошибкам и по накопленному уровню навыков, даже если сам Boss был пройден.
- Импорт TXT/CSV: сначала предпросмотр, затем явное подтверждение. Перед импортом можно назначить слова в урок или создать новый урок.
- В Dictionary можно менять уроки для уже существующих слов.
- Listening исправлен: воспроизводится именно китайское слово (汉字), а не pinyin; есть нормальная и медленная озвучка, статус голосового движка и повторное воспроизведение.
- Quest теперь тоже содержит настоящее аудирование с кнопкой 🔊.
- Writing использует Hanzi Writer с мягким допуском для естественного рукописного ввода; качество влияет на XP/рост навыка.

## Формат импорта

Поддерживаются:
- `享受 xiǎngshòu наслаждаться, получать удовольствие`
- `精打细算 jīng dǎ xì suàn тщательно рассчитывать, экономить`
- `汉字 | pinyin | перевод`
- TSV / CSV-подобные строки.

Файл пользователя `текст.txt` НЕ встроен в приложение и НЕ импортируется автоматически.

## Почему Listening иногда зависит от iPad

Браузер использует системный Speech Synthesis. В iPad доступны системные голоса и их языки, а список голосов может быть динамическим. Если китайский голос отсутствует, откройте на iPad настройки речи и добавьте китайский голос/диалект; затем вернитесь в игру и нажмите `🔊 Слушать`.

## Установка на iPad

1. Разместите папку на HTTPS-хостинге.
2. Откройте ссылку на папку в Safari.
3. Нажмите «Поделиться» → «Добавить на экран "Домой"».
4. Выберите открытие как веб-приложение, если iPad показывает этот пункт.

Для режима Writing при первом запуске нужен интернет: движок Hanzi Writer загружается с CDN. Остальные файлы приложения кэшируются Service Worker.
