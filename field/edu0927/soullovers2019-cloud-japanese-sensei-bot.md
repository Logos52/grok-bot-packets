# 日本語先生 — Telegram-бот для изучения японского «через смыслы»

Персональный сэнсэй в Telegram: учит японскому не в формате «слово = перевод»,
а через **образы и смыслы**, из которых складываются иероглифы.

Основан на идее проекта [japanese-sensei](https://github.com/) (разбор слов по трём
слоям: форма → смысл → употребление), переработан в Telegram-бота на TypeScript/Bun.

## Возможности

- 🎓 **Уроки по программе JLPT N5** — 12 тематических уроков по 5 слов
- 🔁 **Каждый урок строится как**: повторение пройденного (тест) → новая тема → финальный тест
- ↔️ **Двусторонние тесты**: иероглиф → перевод и перевод → иероглиф (4 варианта)
- 🧠 **Память о прогрессе**: бот помнит всё пройденное и «на чём остановились»,
  подбирает вопросы с уклоном в слабые слова, ведёт серию дней
- 📜 **Разбор через смыслы**: радикалы → живой образ → употребление; достоверная
  этимология отделена от мнемоники
- 🧠 **Работает без ИИ-ключей**: все слова курса предразобраны и лежат в локальной
  базе знаний (`knowledge/analyses.json`) — карточки открываются мгновенно;
  свободные запросы разбирает встроенный ИИ, а результат кэшируется навсегда
- 🔊 **Озвучка слов** без ключей (Google TTS; опционально — натуральный голос Gemini)
- 🧩 Свободный разбор: пришли любое японское слово/иероглиф (или русское слово) —
  бот разберёт, озвучит и добавит в твой словарь
- 📊 /progress — точность, серия дней, слабые места; 📖 /words — словарь по урокам

## Технологии

- [Bun](https://bun.sh) + TypeScript — рантайм
- Telegram Bot API — long polling, без зависимостей (чистый fetch)
- LLM: встроенный ИИ окружения (без ключей); Gemini — опциональный резерв
  с автопереключением эндпоинтов (generativelanguage → Vertex AI)
- База знаний: предгенерированные разборы всех слов курса + вечный кэш
  свободных запросов (`data/knowledge.json`) — ИИ не вызывается повторно
- TTS: **Google Translate TTS** (MP3, без ключей); опционально **Gemini TTS**
  (OGG/Opus через ffmpeg, голос Kore) — включается `TTS_PROVIDER=gemini/auto`
- Хранилище: JSON-файл с атомарной записью (`data/db.json`)

## Запуск у себя

```bash
# 1. Установить bun (Linux/macOS/WSL)
curl -fsSL https://bun.sh/install | bash

# 2. Клонировать и зайти в каталог
git clone <repo-url> && cd japanese-sensei-bot

# 3. Зависимости
bun install

# 4. Настройки
cp .env.example .env
# впиши в .env:
#   TG_BOT_TOKEN    — токен от @BotFather
# GEMINI_API_KEY и другие ключи НЕ обязательны:
# учебные слова берутся из knowledge/analyses.json (без ИИ),
# разборы — встроенный ИИ, озвучка — Google TTS (без ключей)

# 5. Запуск (watchdog сам перезапускает бота при сбоях)
bash run.sh
```

### База знаний (без Gemini и без ИИ)

Все 60 слов курса предразобраны по методике «форма → образ → смысл» и лежат
в `knowledge/analyses.json`. Бот отвечает по ним мгновенно, ничего не генерируя.

Пополнить/перегенерировать базу:

```bash
bun scripts/gen_knowledge.ts   # идемпотентен: догенерирует недостающее
```

Свободные запросы ученика (слова вне курса) разбирает встроенный ИИ; каждый
удачный разбор сохраняется в `data/knowledge.json` — повторно ИИ не вызывается.
Gemini при этом не нужен вовсе: он остаётся опциональным резервом для разбора
и озвучки (`TTS_PROVIDER=auto|gemini` в `.env`). Из регионов, где Google API
блокируется (например, Гонконг), клиент сам переключается на Vertex AI —
для этого один раз включите API: https://console.developers.google.com/apis/api/aiplatform.googleapis.com/overview

## Структура

```
src/
├── bot.ts         — главный модуль: роутер, FSM сессий (повторение → тема → тест)
├── telegram.ts    — Telegram Bot API клиент (fetch, long polling)
├── knowledge.ts   — локальная база знаний: мгновенные разборы без ИИ
├── gemini.ts      — опциональный клиент Gemini (API ↔ Vertex), если задан ключ
├── llm.ts         — разборы слов: база знаний → встроенный ИИ → Gemini; промпт «через смыслы»
├── audio.ts       — озвучка: Google TTS (без ключей) / опционально Gemini TTS
├── db.ts          — JSON-хранилище: словарь, история, статистика, серия дней
├── curriculum.ts  — учебный план: 12 уроков JLPT N5 (60 слов)
├── quiz.ts        — генерация двусторонних вопросов с дистракторами
└── cards.ts       — рендер карточек разбора
knowledge/
└── analyses.json  — предгенерированные разборы всех слов курса (в git)
scripts/
└── gen_knowledge.ts — догенерация/обновление базы знаний
material/          — исходный проект-референс (japanese-sensei)
```

## Приватность

- `.env` (токены) и `data/` (личный прогресс) не попадают в git — уже в `.gitignore`.
- Уроки и тесты адаптируются под ошибки ученика: слабые слова спрашиваются чаще.
