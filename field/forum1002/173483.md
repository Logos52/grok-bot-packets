## @deanrie 2026-10-01T10:57:06.269Z STAFF
Hey, thanks for the detailed report.

You described it correctly. The app and the help article don’t match right now. The details panel for personal bots was redesigned recently, and in the new layout there’s no separate Bot settings page with a Description field anymore. Instead, you’ll see Details / Library / Computer. This isn’t Ubuntu-specific and it’s not related to your setup. Everyone on desktop has the same layout right now.

This is a known issue we’re tracking, including the docs mismatch. I’ve shared your report with the team. I can’t give a timeline yet, but I’ll reply in the thread once there’s an update.

Also, thanks for noting that existing bots still speak their original Description. That’s a useful detail, and I passed it along.
