On Cloud environments: Grok Bot can already launch Cursor cloud agents into a saved environment from your cursor.com dashboard, and those runs use that environment’s setup along with your Cloud Agent secrets. What your bot can’t do yet is browse your saved environments on its own, which is why it told you the environment wasn’t set up.

Try giving it the environment’s exact name, for example: “run the tests in a cloud agent using my saved Cloud Agents environment called ”.
