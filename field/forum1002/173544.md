## @Brian_Miller2 2026-10-01T20:53:12.452Z
For those of you using Vercel hosting and have bots validate their SE work in a branch (using Vercel preview link), how are you handling authentication?

There is a bug with 1Password currently where the preview link is not recognized by 1P, therefore even if you have the credentials saved, it won’t autofill or recognize the credentials being associated with the app.

Therefore, even when using the 1P plugin with Grok Bot (in shared with Grok Bot vault), the bot can’t use the shared credentials.

I would think this is a very common issue for others given:

Many are using GB for software engineering E2E
Vercel hosting is common
Vercel preview links are used by branches which bots use during development and self validation
Many devs already use 1P

Having to manually auth the bot for every task is slowing me down tremendously and kind of defeats the point of agentic development.

How is everyone else solving for credential sharing for SE workflows?
