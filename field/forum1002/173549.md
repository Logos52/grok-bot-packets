## @Shaun_Bowe 2026-10-01T21:50:11.929Z
Where does the bug appear (feature/product)?
Grok Bot

Describe the Bug
When switching between bots in the desktop agent the message pane re-paints strange. Sometimes it shows up blank, sometimes it is just cutoff and only some of the messages are there. Scrolling the mouse wheel once fixes the issue and everything paints correctly

Steps to Reproduce

Open Grok Bot Desktop on Windows
Change Bots
See partially filled or blank message screen
Scroll the mouse wheel of move the scroll in the pane up and down and it is fixed.

Expected Behavior
When you switch bots the entire conversation should be there.

Operating System
Windows 10/11

Version Information
GrokBot: 0.66.0

I have a screen recording of the issue but there is too much personal information on it to share. I could send it privately though.

Does this stop you from using Cursor
No - Cursor works, but with this issue
