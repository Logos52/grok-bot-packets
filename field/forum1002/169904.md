## @Johannes_Isabell 2026-08-29T10:44:31.235Z
Feature request for product/service
Cloud Agent (GitHub, Slack, Linear,…)

Describe the request
Two co-founders, one business, one Grok Bot staff.

We both need to message the same bots — Sales, Ops, Chief of Staff — in our own chats, without sharing one login.

Today that is not possible. Each seat gets its own computer and its own roster. Sharing a bot only creates a copy. Copies do not share memory, files, logins, or conversation history, so they drift immediately.

What we want:

One company roster both of us can talk to
Separate private chats per person
Shared working context (memory / files / tool sessions), not just a template
Template sharing and “shared rooms” (same thread, two people) are useful but not this

I am seeing more and more requests for this on X too.

Operating System (if it applies)
MacOS
