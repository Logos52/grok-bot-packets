# Deutsch Lernen — German Learning Flashcards

A free, offline-capable German vocabulary trainer covering the **1,000 most-used German words** across 10 thematic groups of 100 words each.

## Features

- **Flashcards** — German word, simplified phonetic pronunciation, native audio (Web Speech API), flip to see English meaning + example sentence
- **10 word groups × 100 words** = 1,000 words total
- **Quiz** — 10 random questions per group, alternating between meaning and sentence fill-in
- **Keyboard shortcuts** — `←` / `→` to navigate, `Space` to flip
- **No frameworks, no dependencies** — pure HTML, CSS, JavaScript

## Word Groups

| Group | Topic |
|-------|-------|
| G1 | Core Phrases (greetings, pronouns, connectors) |
| G2 | Core Verbs (modals, movement, senses) |
| G3 | Daily Life Verbs (communication, household, reflexive) |
| G4 | People & Body (family, professions, body parts) |
| G5 | Places & Environment (cities, nature, buildings) |
| G6 | Objects & Things (electronics, clothing, transport) |
| G7 | Numbers & Time (1–1000, days, months, seasons) |
| G8 | Adjectives & Colors (size, emotion, color, character) |
| G9 | Food & Drink (ingredients, meals, cooking, restaurant) |
| G10 | Grammar Words (articles, prepositions, conjunctions) |

## Usage

Open `index.html` in any modern browser — no server needed.
