## 📖 项目简介

「汉字宇宙」是一个把中华文化数据变成三维星图的纯前端实验系列。目前包含三个作品：

| 作品 | 一句话简介 | 数据规模 |
|---|---|---|
| 🌌 **星谶**（主打） | 诗人化作星辰、诗篇化作微光的古诗词星图 | 200 位诗人 · 1000+ 诗作 |
| ☀️ **汉字宇宙星系** | 每个汉字都是一个星系，放大后由彩色粒子拼出字形 | 收录 20823 个汉字（新华字典） |
| 📜 **诗云** | 诗人与诗作的关系星图，致敬刘慈欣《诗云》 | 30000+ 诗人规模设定 |

## 🌌 星谶 —— 诗人尽作星辰，诗篇皆化微光

> 时代定其方位，篇章赋其辉光，文脉牵其引线，遂成璀璨诗图。

- **沉浸式星图漫游**：拖拽旋转、滚轮缩放，诗人在宇宙中按朝代方位散落
- **搜索定位**：按诗人、时代或代表作快速检索，镜头自动飞向目标星辰
- **诗人行星**：点击诗人，其诗作如卫星般环绕旋转，附生卒年、籍贯、代表作与评语
- **意象星云**：月 · 酒 · 水 · 山 · 花 · 剑 · 雪 · 梦 · 风，九大意象化作可探索的星云线索
- **朝代时间轴**：先秦 → 汉魏 → 六朝 → 唐 → 宋 → 元明清，一键穿越
- **朗读 / 收藏 / 复制**：诗句支持语音朗读与一键分享

## ☀️ 汉字宇宙星系 —— 每个汉字都是一片星系

- 20823 个汉字（数据取自《新华字典》数据库）随机散布在三维宇宙中，远看是发光的星云节点
- 滚轮无限缩放，靠近某个星系时，**由程序实时用数千彩色粒子"画"出该汉字的字形**，笔锋可见
- 点击星系中心，浮出信息面板：拼音、部首、笔画、结构、释义
- 粒子颜色按部首/笔画映射到不同恒星色系，配合 LOD 与缓存保证流畅

## 📜 诗云 —— 三十万诗人共此星图

- 诗人按时代与作品量排布为星座，诗作化作绕行微光，文学关系以星线相连
- 支持搜索、朝代筛选与诗人详情（关联星体：屈原 · 曹植 · 杜甫 · 苏轼……）
- 附带 Docker / Nginx 一键部署方案（见 [诗云/快速部署指南.md](诗云/快速部署指南.md)）

## 🚀 快速开始

纯前端项目，无需安装任何依赖：

```bash
git clone https://github.com/zwls666/hanzi-universe.git
cd hanzi-universe

# 方式一：直接用浏览器打开
#   星谶/index.html 或根目录 index.html

# 方式二：起一个本地服务器（推荐）
python -m http.server 8000
# 浏览器访问 http://localhost:8000/星谶/
```

诗云支持 Docker 部署：

```bash
cd 诗云
docker-compose up -d
```

> 提示：页面通过 CDN 加载 Three.js，首次打开需要联网。

## 🔧 技术实现

- **Three.js**：星谶/诗云使用 r165（ES Modules + importmap），汉字星系使用 r128 + OrbitControls
- **纯前端单文件**：无构建、无后端，全部逻辑与数据在一个 HTML 里
- **字形粒子化**：隐藏 Canvas `fillText` 渲染汉字 → `getImageData` 采样非透明像素 → 运行时生成 `THREE.Points` 粒子坐标（LOD + 缓存优化）

## 📚 数据来源

- 汉字数据：开源《新华字典》数据库（20823 字，含拼音、五笔、部首、笔顺、释义、说文解字，MIT 许可）。因体积原因未随仓库分发：将其 `新华字典.sql` 放入根目录后运行 `python extract_data.py` 即可重新生成
- 诗人生平与代表诗句：人工整理与艺术化设定，仅供展示
