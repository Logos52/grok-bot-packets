# Klarpunkt LMS & Exam Prep Hub 🇩🇪

An interactive German language learning management system (LMS) and exam study hub built for Goethe & telc A1–B1 exam preparation.

## 🚀 Live Demo
Access the live web application here:
`https://<your-github-username>.github.io/<your-repo-name>/`

## ✨ Features
* **Interactive Course Modules:** Step-by-step lessons covering introductions, grammar rules, formal email writing, and speaking prompts.
* **Practice Quizzes:** Instant feedback quizzes inside lessons to test comprehension.
* **Readiness & Schedule Calculator:** Custom study allocation breakdown based on current test scores in Lesen, Hören, Schreiben, and Sprechen.
* **Progress Tracking:** Local device storage saves completed topics and calculates overall completion percentage.
* **PWA / Mobile Optimized:** Built for high-contrast mobile view and home screen installation.

## 🛠️ Built With
* HTML5
* CSS3 (Responsive Design & Mobile UI)
* JavaScript (Vanilla JS & LocalStorage)
