# Japanese Tutor v0.1

Clean Android starter project for the offline Japanese Tutor.

## GitHub build

The repository is designed for GitHub Actions. Upload the contents of this ZIP to a new repository, then add the Android build workflow.

## Goal

- Offline-first Japanese course
- Hiragana/Katakana
- JLPT N5 → N1
- Progress tracking
- Audio and local AI planned for later versions

This v0.1 is the clean APK-build foundation.
