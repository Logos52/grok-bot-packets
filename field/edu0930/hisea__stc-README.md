# 简明技术中文（STC）

**简明技术中文（Simple Technical Chinese, STC）** 是一套面向技术信息的中文写作规范。

STC 的目标不是把专业内容“写浅”，而是在不损失技术准确性的前提下，使技术文本更：

- **准确**：表达与事实、动作和条件一致。
- **简明**：删除不必要的词语和结构。
- **一致**：同一概念使用同一术语。
- **无歧义**：减少省略、模糊指代和不明确的逻辑关系。
- **可执行**：操作说明能够直接转化为明确动作。
- **易处理**：便于翻译、检索、知识库、机器检查和 AI 处理。

## 适用范围

STC 主要面向：

- 产品说明书
- 操作与维修手册
- 工程技术文档
- 软件帮助文档
- 安全说明
- 标准操作程序（SOP）
- 技术培训材料
- 技术知识库
- 面向机器翻译或 AI 处理的中文技术内容

STC 不以文学表达、公文表达或一般新闻写作为主要目标。

## 基本思想

普通中文允许作者为了语感使用省略、同义替换、长修饰语和上下文暗示。技术文本中的这些特征可能增加理解成本或产生歧义。

STC 优先选择：

> 明确的术语 + 明确的动作 + 明确的对象 + 明确的条件 + 明确的结果

例如：

**不推荐**

> 检查阀门和管道连接，如果发现损坏，应将其更换。

**推荐**

> 检查阀门和管道连接。  
> 如果阀门损坏，更换阀门。  
> 如果管道连接件损坏，更换损坏的连接件。

第二种写法更长，但指代关系明确，因此更符合 STC。

## 设计原则

STC 会参考受控语言、简明语言和技术写作领域已有经验，但不会机械复制英语规则。中文有自己的主要歧义来源，例如：

- 主语和宾语省略
- “其、该、此、它”等指代
- 多层前置修饰语
- 并列结构作用范围不清
- 条件、例外和结果关系不明确
- 同义词在同一文档中任意替换
- 模糊程度词和不确定动作

STC 将优先解决这些中文技术写作问题。

## 版本

STC 使用语义化版本思路：

- **Draft 0.x**：规则仍在形成。
- **1.0**：第一版稳定规范。
- 后续小版本可以增加示例、词汇和解释。
- 规则含义发生不兼容变化时提升主版本。
