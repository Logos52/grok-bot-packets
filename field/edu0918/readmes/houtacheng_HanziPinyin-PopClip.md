# 漢字拼音 PopClip 外掛

選取中文後點擊「拼」，外掛會將兩排文字複製到剪貼簿：第一排是原文，第二排是帶聲調漢語拼音。繁體、簡體中文均可處理；標點、英文與數字會保留。

## 安裝

1. 雙擊 `HanziPinyin.popclipext` 資料夾。
2. PopClip 開啟後，確認安裝。
3. 在任何可選字的 App 選取中文，點擊 PopClip 列上的「拼」。
4. 結果已在剪貼簿，貼到等寬字體的文字區會得到最整齊的對齊。

## 範例

```text
我   今   天    要   去   紐    約
wǒ  jīn  tiān  yào  qù  niǔ  yuē
```

## 說明

- 外掛完全離線運作，不會傳送所選文字。
- 多音字由拼音詞庫按上下文判斷，但個別語境仍可能需要人工校對。
- `pinyin-pro` 3.27.0 已經內嵌進 `Config.js`，使用 MIT 授權；授權條款放在 `vendor/LICENSE-pinyin-pro.txt`。
