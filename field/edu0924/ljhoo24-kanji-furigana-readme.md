# Kanji Study

일본어 웹페이지를 읽을 때 모르는 어휘에만 개인화된 후리가나를 표시하는 로컬 우선 Chromium 확장 프로그램입니다.

도구 모음 버튼이나 단축키를 누르면 현재 페이지를 사이드 패널에서 읽을 수 있습니다. 일본어를 드래그한 상태로 실행하거나 우클릭 메뉴를 사용하면 선택한 부분만 분석합니다.

## 주요 기능

- 확장 도구 모음 버튼 또는 `Ctrl+Shift+K`로 선택 영역 우선 읽기; 선택이 없으면 현재 페이지 읽기
- 선택한 일본어의 우클릭 메뉴에서 선택 영역만 읽기
- Mozilla Readability 기반 본문 추출과 일반 텍스트 폴백
- 로컬 Kuromoji 사전을 이용한 어휘 분리와 읽기 생성
- 한자와 오쿠리가나를 정렬한 후리가나 렌더링
- Chrome 온디바이스 Translator를 이용한 문단·단어 일본어→한국어 번역
- `항상 표시`, `가려서 연습`, `표시 안 함` 개인 설정
- 읽기·의미·청취 상태, 읽기 교정, 원문 노출 이력의 로컬 저장
- Chrome 계정을 이용한 단어 설정·읽기 교정·글자 크기 동기화
- 버전이 포함된 JSON 백업 파일 내보내기·가져오기
- `activeTab` 기반 임시 페이지 접근; 전체 사이트 지속 권한과 외부 분석 서버 없음

실시간 영상 자막과 원문 페이지 위의 인라인 후리가나는 지원하지 않습니다.

## 개발 및 빌드

Node.js가 필요하다.

```powershell
npm install
npm run build
npm test
```

빌드된 확장은 `dist` 폴더에 생성된다.

## 다른 PC에서 사용

배포용 ZIP은 [GitHub Releases](https://github.com/ljhoo24/kanji-furigana/releases/latest)에서 내려받을 수 있습니다. 아래 설치 순서에 따라 압축을 풀어 Chrome에 로드하세요.

개발 PC에서 다음 명령으로 설치용 ZIP을 만든다.

```powershell
npm run package
```

`release/kanji-v<버전>.zip`이 생성된다. 다른 PC에서는 다음 순서로 설치한다.

1. ZIP을 원하는 영구 폴더에 압축 해제한다. 설치 후 그 폴더를 이동하거나 삭제하지 않는다.
2. Chrome에서 `chrome://extensions`를 연다.
3. 우측 상단의 `개발자 모드`를 켠다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누르고, 압축을 푼 폴더를 선택한다.
5. 이후 새 ZIP으로 업데이트할 때는 같은 폴더의 파일을 교체하고 확장 카드의 새로고침 버튼을 누른다.

Chrome 웹 스토어를 사용하지 않는 개인 배포 방식이라 각 PC에서 위 절차를 한 번 수행해야 한다. 고정 확장 ID 적용 후에는 단어 학습 상태와 화면 설정이 같은 Chrome 계정의 PC 사이에서 동기화되며, 문서·노출 이력은 각 PC에만 남는다.

## 단어 설정 동기화와 백업

사이드 패널 상단의 `동기화됨` 버튼을 누르면 Chrome 동기화 사용량과 다음 작업을 확인할 수 있다.

- `지금 동기화`: 로컬 단어 설정과 Chrome 계정의 설정을 최신 수정 시각 기준으로 병합
- `백업 파일 저장`: 단어 상태, 읽기 교정, 글자 크기를 JSON 파일로 저장
- `백업 파일 가져오기`: 다른 설치본이나 새 확장 ID로 설정 복원

문서 원문과 노출 이력은 Chrome 동기화의 100KB 제한 때문에 각 PC의 IndexedDB에만 저장한다. Chrome 설정에서 동기화가 꺼져 있으면 `storage.sync`는 해당 PC의 로컬 저장소처럼 동작한다.

v0.5.0부터 manifest 공개 키로 확장 ID를 `dhebihhjgndplfjedggdgohmfjioicpf`에 고정한다. v0.4.0 이하에서 처음 전환할 때는 기존 백업 JSON을 한 번 가져와야 하며, 이후 같은 배포 ZIP을 설치한 PC끼리는 같은 Chrome 계정의 동기화 저장소를 공유한다.

## 데이터와 개인정보

- 페이지 분석과 일본어 형태소 분석은 확장 프로그램 내부에서 처리합니다.
- 읽은 문서와 노출 이력은 해당 PC의 IndexedDB에만 저장합니다.
- Chrome 계정 동기화에는 단어 상태, 읽기 교정, 글자 크기만 저장합니다.
- 번역은 Chrome의 온디바이스 Translator API를 사용하며 별도의 번역 서버를 운영하지 않습니다.

## Chrome에서 실행

1. `chrome://extensions`를 연다.
2. 우측 상단의 `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누른다.
4. 이 프로젝트의 `dist` 폴더를 선택한다.
5. 일본어 웹페이지에서 Kanji 버튼이나 `Ctrl+Shift+K`를 누른다. 드래그한 텍스트가 있으면 그 부분만, 없으면 페이지 전체를 읽는다.

단축키가 다른 기능과 충돌하면 `chrome://extensions/shortcuts`에서 변경할 수 있다.

## 현재 제한

- 실시간 영상 자막과 원문 페이지 위의 인라인 후리가나는 지원하지 않는다.
- Chrome 138 미만에서는 번역을 제외한 리더 기능만 사용할 수 있다.
- 번역은 문맥에 따라 부정확할 수 있는 자동 번역이며, 사전식 뜻과 예문 데이터는 아직 포함하지 않았다.
- 단어 경계 합치기·분리는 아직 포함하지 않았다.
- Chrome 116 이상을 우선 지원하며 다른 Chromium 브라우저는 별도 검증이 필요하다.
- 로컬 사전을 포함하므로 빌드 크기는 약 18MB다.
