# TOPIK I 실전 모의고사 10회 (Luyện đề TOPIK I)

Web app luyện thi TOPIK I dành cho người Việt — 베트남 학습자를 위한 TOPIK I 실전 모의고사.

- 10회분 · 회당 70문항 (듣기 30문항 40분 / 읽기 40문항 60분 · 200점)
- 문항별 듣기 버튼 + 실제 시험처럼 이어지는 듣기 파일 (`audio/testNN.mp3`)
- 상단 카운트다운 타이머, OMR 답안지, 자동 채점 · 등급 판정 (1급 80점 / 2급 140점)
- 문항별 베트남어 해설 · 어휘 · 듣기 대본

문항은 실제 TOPIK I 형식에 맞춰 새로 만든 창작 문항이며, 국립국제교육원(NIIED) 공식 기출문제가 아닙니다.
