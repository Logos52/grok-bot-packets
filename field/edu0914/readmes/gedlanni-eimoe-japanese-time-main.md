# 绘萌酱 · 日语时光（EIMOE Japanese Time · r3）

一个**本地优先、双击即用、零第三方依赖、断网可用**的日语自学网页应用。
给「基础很少、想在某个考试日冲 JLPT N3」的人用：五十音与笔顺、发音、词汇 SRS、语法、汉字、迷你模考、每日计划，外加一个会看你真实数据的元气学妹陪练 **绘萌酱**。

> **在线直接用（推荐）**：https://gedlanni.github.io/eimoe-japanese-time/
> 用 **Edge** 打开效果最好（浏览器日语语音合成在 Edge 上最省事）。
> 数据全在你的浏览器里（localStorage）：**没有账号、没有云同步、不上传任何内容**。

---

## 一、三种用法

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **在线**（最省事） | 打开 https://gedlanni.github.io/eimoe-japanese-time/ | 只想马上开始学、手机也能用 |
| **下载到本机** | `Code → Download ZIP` 解压 → 双击 `start.bat`（推荐）或直接双击 `index.html` | 想要完全离线、把记录留在自己电脑上 |
| **克隆仓库** | `git clone https://github.com/gedlanni/eimoe-japanese-time` 然后双击 `start.bat`（没装 Git 就用上面的 Download ZIP） | 想改内容、想提 Issue/PR |

- `start.bat` 会用 node 起一个本地静态服务（端口 8120，自动开浏览器）；**没装 Node 也能用**，直接双击 `index.html` 即可（部分浏览器会限制 `file://` 下的存储，建议用 `start.bat`）。
- 要求：Windows（其它系统也能跑，双击 `index.html`）；浏览器建议 Edge。做题/判分/存档全在本地。

## 二、发音怎么来的（重要，先看这段）

**本仓库不包含任何预生成音频文件**：语音是用 CeVIO Creative Studio 合成的，而各声源的使用条款**不允许把生成的 wav 随程序分发**。所以公开版的发音是这样降级的：

| 层 | 公开版状态 | 说明 |
|---|---|---|
| ① 预生成音频包 | **空**（0 条） | 想要就自己生成：装好 CeVIO → 双击 `cevio.bat --pack kana`（假名 208 条）或 `--pack all` |
| ② CeVIO 实时朗读 | 需要你自己起代理 | 双击 `cevio.bat`（代理监听 `127.0.0.1:8128`），细见 `README-audio.md` |
| ③ **浏览器日语合成** | **默认就用这一层** | Edge：设置 → 语言 → 添加「日语」，然后**重启浏览器** |

- 所以：**开箱即用时发音走浏览器合成**；想要更好听的人声，按上面 ①② 自己接 CeVIO。
- 设置页 → 发音，会显示当前用的是哪一层；也可以手动指名只用某一层（`auto / pack / cevio / browser / off`）。

## 三、AI 陪练（可选，用自己的 key）

- **不填 key 也能用**：绘萌酱会走**本地规则陪练**（依据你真实的到期卡片、错题、笔顺错误类型给任务，并明说自己是本地模式）。
- 想接大模型：把 `ai-config.example.json` 复制成 `ai-config.json`，填上**你自己的** `apiKey`（任何 OpenAI 兼容端点都行：DeepSeek / 中转站 / LM Studio / Ollama 的 `/v1`），然后双击 `ai.bat`。
- `ai-config.json` 已被 `.gitignore` 忽略，key **只存在你本机**，不会进浏览器存储、不写日志。

## 四、功能一览

| 页签 | 做什么 |
|---|---|
| **五十音** | 208 个假名（清音/浊音/半浊音/拗音 × 平假/片假）。点格子看卡片并**直接发音**；`认 / 拼 / 听` 三种小测；每个假名有独立 SRS 记忆状态 |
| **笔顺** | 米字格/田字格/空白；参考字形四档（描红 / 字帖 / 骨架 / 关，快捷键 J）；抬笔即判（六项加权 + 六道封顶闸门，乱涂拿不到高分）；**判分时朗读这个字**；另有「认字」按钮（只看字形猜字）；数位板压感会改笔迹粗细 |
| **词汇** | 300 个 N3 核心词，SRS 间隔 1→3→7→14→30→60→120 天；翻卡 / 认读 / 拼写 / 听写 / 错题五种模式；卡片下方有**手写板**（可识别、可跳笔顺） |
| **语法** | 60 个 N3 语法点：接续公式、例句（带读音与中文）、易错对比、关联跳转；可单点考这条语法 |
| **汉字** | 220 个字：画数、部首、音读、训读、例词；一键跳到笔顺板写一遍 |
| **模考** | 15 分钟迷你卷 / 40 分钟半套 / 只考错题；交卷出成绩单（分项正确率、用时、错题解析、建议复习清单）；**可导入自己的题库**（格式见 `docs-题库格式.md`） |
| **计划** | 考试倒数、今日三关（点「▶ 开始」直接进对应练习）、**真实学习时长**、连续打卡、日历热力图、正确率与笔顺/模考最好成绩 |
| **设置 / 自检** | 环境自检（含**数位板压感**实测读数）、压感参数 + 试写区、发音三层状态与试听、数据导出/导入/备份、考试日与每日时长 |

右侧常驻绘萌酱面板：6 维能力画像、对话、本次会话统计。

**常用快捷键**：`1…8` 切页签 · 笔顺页 `空格` 判分（成绩卡开着再按 = 下一题）· `Ctrl+Z` 撤销 · `N/P/R/G` 下一个/上一个/随机/换格子 · `J/K/L` 参考字形与编号箭头 · `?` 打开帮助。

## 五、内容与规模

五十音 **208** · 词汇 **300** · 语法 **60** · 汉字 **220** · 阅读 **30** · 题库 **270**（＋你自己导入的）。

> 内容是作者按 JLPT 常见出题方式编写的**练习材料**，**不是官方真题**；考前请务必用官方问题集/真题核对。

## 六、开发者：测试

零依赖，装个 Node 就能跑（每个文件自己打印结果，全绿时 exit 0）：

```bat
node tests\run.js        :: 学习内核：SRS 数学 / 内容索引 / 陪练规则
node tests\content.js    :: 内容库完整性
node tests\strokes.js    :: 笔顺几何 + 评分（含乱涂严格性回归）
node tests\quiz.js       :: 做题引擎 / 组卷 / 错题本
node tests\exam.js       :: 模考组卷 / 判分 / 成绩单
node tests\bank.js       :: 题库导入 / 校验 / 合并
node tests\audio.js      :: 发音层链（全桩，不发声）
node tests\hand.js       :: 手写识别内核（识别率 / 形近字 / 噪声 / 性能）
node tests\ink.js        :: 毛笔描红轮廓内核
node tests\domcheck.js   :: 静态一致性（id / 资源 / 页签 / 字数命名空间 / 版本戳）
node tests\boot.js       :: 启动烟雾：真跑 boot()、真渲染八个页签、真走事件链路
```
笔顺几何来自 [KanjiVG](https://kanjivg.tagaini.net/)（CC BY-SA 3.0），由 `tools/fetch-strokes.js` 抓取转换；`node tools\fetch-strokes.js --selftest` 可离线自检。
