It’s becoming less and less reasonable to use Grok for coding. After Opus reviews the code, it finds 10-15 problems in simplest features. Grok cares the absolute least about how it writes your functionality. It doesn’t care what it will affect, that it decreases the safety, that it affects the user experience. It just doesn’t care. I have never seen the model destroying the code like that from simple tasks. With every feature, the whole website just falls apart and breaks. Not only the features it worked on. It just never happened with GPTs 5.1 - 5.6 or Opus 4+, yet alone Astra or Fable.
Grok wants to execute your request with the least effort, so least that it will break something else if it will make things easier. But it’s not even fast. It still takes so much time while it thinks and confirms that it did the job the absolute laziest way possible and broke something. The only decent experience you can get from Cursor is by using Other Models pool, where usage is not designed for full time coding. Any code written by Grok is getting rewritten almost entirely by Opus or Muse Max, which I found surprisingly good and hard working. Muse traces problems the most to fix only them and not affect anything else.
You cannot rely on Grok at all. And UI looks like 90s, even when I have all the styles done, the website is in production, I just need to write new similar tabs, buttons, boxes like I already have. And it looks entirely broken. I ask it if it supposed to look like that, and he says yeah, it’s finished. And I need to use Opus to one shot the entire Grok’s work with amazing UI, with several improvements over my current styles. The difference in experience is so drastic that it’s hard to justify paying for Cursor, especially considering how buggy it is and how terrible the Origin experience is (I thought it will be the best, since it’s one ecosystem lol), like I can’t even see my Origin repos in the mobile app and team confirms every time that “yes, it’s how it works for now, we will fix it sometime”.
My favorite function in AI apps is dictation and it’s 5x worse than in ChatGPT. Although, I want to support xAI the most and I do want to use their products, including GrokBot that I love, besides it feels like it works on Grok 3, the dumbest of all Groks in all apps. GrokBot just does the opposite of what you directly ask, but that’s a whole another story.
