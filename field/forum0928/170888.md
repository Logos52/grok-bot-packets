## Post 8 @deanrie · 2026-09-10T05:11:37.543Z
Hey Dominik, good request. A lot of users get tripped up here.
For Grok Bot, Cursor Ultra and SuperGrok Heavy are on the same top tier. Both give the highest weekly Grok Bot quota, and neither gives more than the other. There is also no difference in models, speed, or priority. Grok Bot works the same on both. If an account somehow has both, the quotas do not stack. You just keep the highest one.
The real difference is what else each plan includes:

Cursor Ultra is a Cursor subscription. Besides Grok Bot, it includes Ultra-level usage for Cursor itself editor, Agent, Cloud Agents, etc.
SuperGrok Heavy is an xAI subscription. Besides the Grok Bot usage grant, it includes SuperGrok Heavy features on grok.com and in the Grok apps. It does not include a Cursor plan. Linking SuperGrok gives your Cursor account the Grok Bot quota, but it does not change your Cursor plan. The earlier offer free Cursor Ultra with Heavy ended at the end of August and is no longer available.

So if you only need Grok Bot, pick based on which extra features you will actually use. If you also plan to code in Cursor, Ultra gives you everything in one place. If you want Grok’s own features, go with Heavy.
With either plan, once the weekly quota is used up, you can keep going via on-demand usage if you enable it on cursor.com with a saved payment method.

## Post 10 @deanrie · 2026-09-20T15:36:47.410Z
Hey, important nuance: usage for Grok models inside Cursor (in the editor, Agent, etc.) comes from your Cursor subscription, not from SuperGrok.
SuperGrok Heavy is an xAI subscription. It gives a grant for Grok Bot usage on the linked Cursor account, but it doesn’t change your Cursor plan and doesn’t add Grok model usage inside Cursor. So if you specifically need Grok models in the editor, that comes from your Cursor plan (Pro / Ultra), and Ultra includes more usage than Pro.
I won’t list the exact included limits per model here, since they depend on the plan and current configuration and they change from time to time. The current breakdown by model is always visible in Dashboard > Usage, and pricing is here:

Models & Pricing | Cursor Docs

So for your case (Grok Bot + Grok models): Cursor Ultra covers both in one place, top-tier Grok Bot and Ultra-level Grok model usage inside Cursor. SuperGrok Heavy only covers Grok Bot and Grok features on the xAI side, not Grok model usage inside Cursor.
