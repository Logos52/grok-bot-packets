# 日本語ノート

My study notes from TCJ Japanese classes (O-ML2511) — weekly review sheets and
practice tests, written with full furigana and English glosses.

**→ [arcade0101.github.io/tcj-japanese](https://arcade0101.github.io/tcj-japanese/)**

Textbooks: 『いっぽ にほんご さんぽ 3』(スリーエーネットワーク) and 『ひらく にほんご』.

## What's here

| | |
|---|---|
| `index.html` | Week index — the site home |
| `grammar.html` | Every grammar point so far, searchable, filterable by day |
| `kanji.html` | Every kanji, with kun/on readings and compounds |
| `vocab.html` | Every word, searchable, with a hide-one-side self-test |
| `src/<date>/` | Page sources, in Artifact format — **edit these** |
| `<date>/review.html` | Built review sheet, with furigana and English toggles |
| `<date>/quiz.html` | Built JLPT-format test, auto-graded, 90% to pass |
| `assets/site.css` | Shared palette, site nav and common components |
| `tools/wrap.py` | Wraps a source page into a standalone page + site nav |
| `tools/render.py` | Renders a class PDF to page images and contact sheets |
| `podcast/<ep>/script.md` | Episode script — transcript **and** its reading-trap table |
| `tools/podcast.py` | Builds ElevenLabs Text-to-Dialogue input, and generates audio |

`src/` is the source of truth. The files beside it at `<date>/` are generated by
`wrap.py` — don't hand-edit those, they get overwritten.

## What's *not* here

The class PDFs and the textbook pages inside them. They belong to the school and
the publisher, and this repository is public — so `.gitignore` keeps every
`*.pdf` out. The PDFs stay in `~/Desktop/TCJ Learning Materials/`.

These pages are my own notes: summaries, grammar tables, example sentences and
questions written for my own revision.

## Adding a week

Run **`/tcj`** in Claude Code — it reads the new deck, writes the pages, updates the
index and the three reference pages, checks both layouts, and pushes.

By hand:

1. Render the deck so the slides can be read (they're photographs, not text):

   ```bash
   python3 tools/render.py "~/Desktop/TCJ Learning Materials/<file>.pdf"
   ```

2. Write `src/<date>/review.html` and `src/<date>/quiz.html`, copying the structure
   of `src/2026-09-14/`. Artifact format — a fragment, no `<!doctype>` / `<html>` /
   `<head>` / `<body>`.
3. Build them:

   ```bash
   python3 tools/wrap.py src/<date>/review.html <date>/review.html
   python3 tools/wrap.py src/<date>/quiz.html   <date>/quiz.html
   ```

   `wrap.py` adds the doctype, `charset` and `viewport` meta, the shared stylesheet
   at the right relative depth, and the site nav.
4. Add the week to `index.html` (newest first) and append the new grammar, kanji and
   words to `grammar.html`, `kanji.html` and `vocab.html`.
5. Commit and push — GitHub Pages redeploys on its own.

## Podcast

One grammar point per episode, two hosts, NHK-style. `script.md` is the source of
truth: it holds the readable transcript with kanji, plus a table of words the TTS
mispronounces. `tools/podcast.py` applies that table so the audio says こない, not
きない — while the transcript you read keeps 来ない.

```bash
python3 tools/podcast.py podcast/ep01           # build tts.json + report length
python3 tools/podcast.py podcast/ep01 --generate --takes 3
```

Set `ELEVENLABS_API_KEY`, `AOI_VOICE_ID` and `KEN_VOICE_ID` first. Output is
nondeterministic, so `--takes` generates several and `seeds.json` records the seed
behind each one — `--seed <n>` reproduces a take you liked. Rejected takes are
gitignored; keep the winner as `episode.mp3`.

## Running it locally

```bash
python3 -m http.server 8000
```
