## 🗺️ Language Learning Roadmaps

1. **[نقشه راه یادگیری زبان کره‌ای (TOPIK)](Roadmaps/01_Korean_Hangul_TOPIK_Roadmap.md):**  
   مسیر ۴ مرحله‌ای از یادگیری ۲ ساعته الفبای هانگول تا واژگان بقا و تکنیک‌های نگارش انشا برای آزمون TOPIK II.
2. **[نقشه راه یادگیری زبان ژاپنی (JLPT)](Roadmaps/02_Japanese_Gojūon_JLPT_Roadmap.md):**  
   تسلط بر هیراگانا و کاتاکانا، گرامر فاعل-مفعول-فعل (SOV مشابه فارسی) و ورود به سطوح N5 تا N3.
3. **[نقشه راه یادگیری زبان آلمانی (Chancenkarte)](Roadmaps/03_German_CEFR_A1_B2_Chancenkarte.md):**  
   برنامه‌ریزی دقیق سطوح A1 تا B2 جهت احراز شرایط قانونی کار و مهاجرت مهندسی و درمانی به آلمان.
4. **[نقشه راه زبان فرانسه (Express Entry)](Roadmaps/04_French_Express_Entry_Canada_Roadmap.md):**  
   استراتژی دستیابی به سطح B2 (NCLC 7) برای تصاحب حداکثر ۵۰ امتیاز مازاد در سیستم مهاجرتی فدرال کانادا.
