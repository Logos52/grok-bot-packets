## #5 deanrie [STAFF] · 2026-08-29T19:22:14Z
Hey, thanks for the request, the screenshots really help clear things up. Point by point: No, Grok Bot usage does not spend your Pro credit of 20 USD per month for specific models in Cursor IDE. Grok Bot on Pro has its own separate included weekly allowance, tracked separately. The percentage meter inside Grok Bot (like the 35%) is the accurate indicator of Grok Bot usage. So, the 69,94 USD shown for Grok Bot did not use any of your 20 USD for Other Models. Specific models (non Auto) in Cursor are still available as usual. Important note about pool isolation: the separation only works within Grok Bot’s included weekly limit. Once that weekly pool is used up, any further Grok Bot usage, if you have On-Demand enabled, goes into the shared On-Demand pool, the same one used for the rest of Cursor usage. You have on-demand turned off, so spillover can’t happen right now. After the weekly pool is exhausted, Grok Bot will just hit the limit instead of charging anything. If you ever enable on-demand and want to be safe, you can set an On-Demand limit on cursor.com in Dashboard > Usage / Billing, including 0 USD to fully prevent spillover. More details: Plans and billing | Cursor Docs Why Grok Bot lines still show up on the Cursor dashboard as Included in Pro: both products run under one account and shared billing, so usage is shown together even though limits come from different pools. The dashboard does not currently split usage by product, and I know that can make it look confusing. Let me know if anything still doesn’t line up.
