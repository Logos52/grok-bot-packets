## #6 mohitjain [STAFF] · 2026-09-28T08:37:08Z
Hey @Capital_EyeMotors ! 1. Scheduling. That option isn’t on your account yet, so the Update button is all you’ll see for now. The help page is a bit ahead of itself there, sorry for the confusion. When it does arrive it lets you set a daily time (not specific days, so no weekends-only), with an option to auto-apply future updates too. 2. Automatic Updates toggle. That one, and the autoUpdateWhenIdleOptIn value you found, only updates the Grok Bot app, not the Computer. There’s no “update the Computer when idle” switch today. It can self-update once it’s sat idle long enough to sleep, but you can’t time it, and with several assistants sharing one Computer it rarely gets that gap. So the reliable path is still pressing Update at a quiet time. You can do that from the iPhone app too, so no one has to be at the Mac. I’ve passed along the ask for scheduled/overnight updates.
