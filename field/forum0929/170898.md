## #7 mohitjain [STAFF] · 2026-09-08T08:18:26Z
Hey @jsolly - this is a labeling issue, not a sign-in that’s actually failing. The GitHub plugin authenticates with the personal access token you enter under Setup Values (Edit Values), not a browser sign-in, so the badge shows Needs auth and the Authenticate button has no link to open (hence the toast). Your connector is already working — the 47 tools are loading with your token, so you can ignore that label (the custom PAT MCP you set up isn’t needed). Quick confirm: in any bot, ask “Using the GitHub connector, which GitHub user am I signed in as?” - if it returns your username, you’re good. This is an issue we’re tracking and I’ve added your report to it; I’ll follow up here when there’s an update. For the Cursor IDE, could you share the exact screen and status text you see there? That’s a different path, so I’d like to look at it separately.
