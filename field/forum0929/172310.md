## #6 kevinn [STAFF] · 2026-09-19T00:42:44Z
Hey @ZeroTwo , thanks for the report. You’re right that the Connect button is misleading on Windows. Currently, connecting 1Password is a one-time setup step that must be completed in Grok Bot on a Mac with the 1Password app installed. After that, you can use Grok Bot on Windows and approve credential requests there as usual. If you don’t have access to a Mac, there isn’t currently a Windows setup path. We’ve let the team know about both the Windows support request and the Connect button behavior.
