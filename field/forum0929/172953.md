## #9 Colin [STAFF] · 2026-09-28T18:07:47Z
Hey @jsolly , thanks for the suggestion! There isn’t an Edit button for custom servers yet, but you can re-point them in place today. Ask your bot to add each server again using exactly the same server name it was registered under, with the new command/args (and the env values it needs). That updates the existing server instead of creating a new one, so its custom instructions stay as they are. Please don’t uninstall first. Uninstalling is what clears the instructions. Once all four point at your mcp-wrappers folder, restart MCP and they should survive the next computer rebuild.
