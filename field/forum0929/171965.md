## #5 deanrie [STAFF] · 2026-09-19T11:30:14Z
Hey, thanks for the report and for the screenshot with the Request ID. Your prompt looks fine. This isn’t something in your project or setup. The block is coming from a content filter on the model side that Auto picked for these requests. Over the last few days, that filter has been mistakenly flagging some normal dev prompts like pasted logs, stack traces, hostnames, and DB status or field logic as sensitive. This is a known issue, we’re tracking it with the provider, but I can’t share an ETA yet. What should unblock you right now: In the model picker at the bottom of the chat, switch from Auto to a specific model for these requests, like Claude or GPT. You can switch back to Auto later. If you want to stay on Auto, trim pasted logs and error output down to one or two key lines and remove hostnames and ports before sending. If the issue happens again on a specific model already, not through Auto, send a fresh Request ID using right upper corner of chat > Copy Request ID in the error block and we’ll take a closer look.
