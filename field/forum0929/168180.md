## #6 mohitjain [STAFF] · 2026-08-13T08:35:08Z
Hey! Thanks for the detailed report. Your Always allow setting is genuinely set, so this isn’t something you misconfigured - it’s an issue we’re tracking. To unblock you now: Fully quit Grok Bot with Cmd+Q (closing the window isn’t enough). In Terminal, run ps aux | grep local-exec-daemon and kill any leftover processes. Relaunch Grok Bot. In Settings → Agent → Execution on Local Computer, switch to Ask every time, then back to Always allow. Updating alone won’t clear this, so run the steps even on the newest build. Let me know if ExternalShell still errors afterward.
