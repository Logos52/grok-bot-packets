Introducing the Agents API | OpenAI
September 10, 2026

Today, we're introducing the Agents API in public beta, bringing that same harness and infrastructure that powers Codex to developers through a simple, flexible API.

With the Agents API, you can create a production-ready agent in a single API call by specifying the task, model, tools, and environment. OpenAI hosts and maintains the harness. You choose the agent's compute environment: in an OpenAI-managed sandbox, on your own infrastructure, or with one of our sandbox partners.

Key capabilities: durable sessions with automatic context compaction; tool search and programmatic tool calling (MCP, custom functions, web search); multi-agent support with parallel subagents; OpenAI hosted sandboxes or partner sandboxes (Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, Vercel).

The Agents API is powered by the open-source Codex harness. Available in public beta to all developers with no additional API fees — pay for tokens and tools used. During public beta, OpenAI will iterate toward general availability based on feedback.
